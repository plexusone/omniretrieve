## [0.1.0] - 2026-01-11

### Highlights

- Initial release of OmniRetrieve - a unified retrieval library for Go
- Support for Vector RAG, Graph RAG, and Hybrid retrieval strategies

### Added

- Core retrieval interfaces (`Retriever`, `Query`, `Result`, `ContextItem`) ([`28e9a14`](https://github.com/plexusone/omniretrieve/commit/28e9a14))
- Vector retrieval with `Index`, `BatchIndex`, and `IndexManager` interfaces ([`2b9ecd3`](https://github.com/plexusone/omniretrieve/commit/2b9ecd3))
- Graph retrieval with `KnowledgeGraph` and `GraphManager` interfaces ([`9282af6`](https://github.com/plexusone/omniretrieve/commit/9282af6))
- Hybrid retrieval with configurable policies (`Parallel`, `VectorThenGraph`, `GraphThenVector`) ([`814a065`](https://github.com/plexusone/omniretrieve/commit/814a065))
- Observability support with span tracing (Phoenix, Opik, Langfuse compatible) ([`6378c60`](https://github.com/plexusone/omniretrieve/commit/6378c60))
- Reranking support (`CrossEncoder`, `Heuristic`, `Chain`) ([`7ad8afd`](https://github.com/plexusone/omniretrieve/commit/7ad8afd))
- In-memory implementations for testing (`VectorIndex`, `KnowledgeGraph`, `HashEmbedder`) ([`5be3a79`](https://github.com/plexusone/omniretrieve/commit/5be3a79))
- pgvector provider with HNSW/IVFFlat index types, batch operations, and JSONB metadata filtering ([`43481c0`](https://github.com/plexusone/omniretrieve/commit/43481c0))

### Documentation
