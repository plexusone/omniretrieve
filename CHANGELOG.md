## [0.1.0] - 2026-01-11

### Highlights

- Initial release of OmniRetrieve - a unified retrieval library for Go
- Support for Vector RAG, Graph RAG, and Hybrid retrieval strategies

### Added

- Core retrieval interfaces (`Retriever`, `Query`, `Result`, `ContextItem`)
- Vector retrieval with `Index`, `BatchIndex`, and `IndexManager` interfaces
- Graph retrieval with `KnowledgeGraph` and `GraphManager` interfaces
- Hybrid retrieval with configurable policies (`Parallel`, `VectorThenGraph`, `GraphThenVector`)
- Observability support with span tracing (Phoenix, Opik, Langfuse compatible)
- Reranking support (`CrossEncoder`, `Heuristic`, `Chain`)
- In-memory implementations for testing (`VectorIndex`, `KnowledgeGraph`, `HashEmbedder`)
- pgvector provider with HNSW/IVFFlat index types
- Batch operations via COPY and multi-row INSERT
- JSONB metadata filtering support
